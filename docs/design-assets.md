## SNS 게시물 선택 예시

Figma `3-3 게시물 선택`에 보이는 예시 썸네일만 `drawable-nodpi/sns_post_*.png`에 로컬로 포함합니다. 이 썸네일은 SNS 연동 대신 화면과 선택 동작을 확인하는 모의 자료이며, 사용자가 선택한 사진이나 실제 SNS 게시물 데이터가 아닙니다. 실행 화면 캡처는 저장소에 포함하지 않습니다.

`3-4 반복 단서 확인`은 선택한 모의 게시물만 썸네일로 보여 줍니다. Figma의 하천 산책로 카드에는 `3-3`에서 선택되지 않은 비행기 사진도 예시로 보이지만, 앱은 게시물 선택 상태와의 일관성을 우선합니다. 카드의 단서와 사진 수는 고정된 모의 연결 관계로 계산하며 실제 이미지 분석 결과가 아닙니다.

`3-5 누적 노출 결과`는 같은 선택 게시물과 ‘맞아요’로 확인한 단서만 집계합니다. 편의점 모의 연결은 아파트 단서와 겹치지 않는 3장으로 구성해 기본 결과가 10개 중 8개가 되도록 맞췄습니다. 중복 단서가 있으면 게시물 수는 중복 없이 집계합니다. 점수 78과 위험도 ‘높음’은 고정 Figma 예시로, 실제 분석이나 위험도 계산을 하지 않습니다. 확인된 단서가 없으면 점수 대신 대시를 표시합니다.

결과 화면의 집(20dp)·방패(18dp)·알림(18dp)은 해당 Figma 프레임의 원본 SVG를 SDK로 변환한 `figma_sns_result_*` 벡터입니다. 썸네일은 선택한 게시물에 따라 동적으로 표시합니다. 전체 보기의 별도 화면은 정의되지 않아 비활성화하고, 이번 범위에서 합의한 대로 일괄 보호 편집과 미리 알림도 비활성화합니다. 토글은 꺼진 상태를 표시합니다. 모의 결과와 준비 중 기능 안내 문구는 실제 동작으로 오해하지 않도록 추가합니다.

## 레이아웃과 범위

`KkokColors`, `KkokTypography`, `KkokSpacing`에서 공통 스타일을 관리합니다. 작은 화면·큰 글자에서는 내용이 줄바꿈되고 스크롤되며 하단 탭은 고정됩니다. Android의 상태바·화면 잘림 영역·제스처 바 안전 여백으로 인해 Figma의 기기 프레임과 상하 배치가 달라질 수 있습니다. 프레임 모서리나 상태바 이미지는 앱 콘텐츠로 복제하지 않습니다.

홈의 위치 노출 검사와 SNS 누적 검사 진입점을 활성화합니다. 보호 편집·알림·기록·마이는 각각 구현 범위에 따라 연결합니다. 사용자가 승인한 Android 시스템 Photo Picker를 사용하는 단일 사진 검사 화면은 Figma `29:52`의 내부 갤러리와 외형이 다릅니다. 사진 선택 뒤 위치 입력은 `59:520`, 입력 오류는 `63:865`에 맞춥니다. 장소 검색·지도·GPS 연동이 없으므로 지도와 주소는 모의임을 화면에 명시하고, 위치는 메모리에만 보관합니다. 검사 중·결과·실패 화면은 각각 `30:120`, `30:191`, `63:954`를 기준으로 구현합니다. 모의 안내 문구를 표시하고 과거 게시물 비교·반복 노출 경고·`3 / 3` 표시는 제외합니다. 저장·수정 버튼은 비활성화하며 실패 안내는 사진 읽기/모의 검사 실패에 맞게 적용합니다. 선택 사진은 동적 콘텐츠이며 단서 영역은 고정 모의 예시입니다.

## 모든 데이터 삭제 확인

Figma `6-6 모든 데이터 삭제` (`63:1167`)의 모달 `63:1251`을 기존 마이 화면 위에 표시합니다. 원본 52×52dp 마스코트 SVG를 SDK로 변환한 `figma_delete_mascot`을 자연 크기로 사용하며, 배경은 Ink 45%입니다. 이름은 합의한 ‘테스터’를 유지합니다.

삭제 확인 이후의 동작은 Figma에 정의되지 않아 보류하고 ‘모두 삭제’를 비활성화합니다. 모의 화면이라는 안내 문구를 추가하며 실제 데이터나 모의 기록을 바꾸지 않습니다. 취소·Android 뒤로 가기는 모달만 닫습니다. 실행 화면과 Figma의 로컬 비교는 수행하되, 2026-10-27 사용자 합의에 따라 PR 이미지 첨부는 생략합니다.

## 가입 완료 화면

Figma `0-3 가입 완료` (`61:740`)는 이름을 합의한 ‘테스터’로 표시합니다. 약관 뒤에는 모의 완료 화면으로 이동하며 계정이나 위치 정보를 만들거나 저장하지 않습니다. ‘장소 등록하기’는 기존 민감 위치 화면을, ‘꼭꼭 시작하기’와 ‘나중에 할게요’는 기본 화면을 엽니다. 현재 앱의 모의 프로필에서 로그인·가입 화면을 여는 별도 진입점은 Figma에 정의되어 있지 않아 추가하지 않았습니다.
